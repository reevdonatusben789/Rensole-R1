# Rensole R1 (a Reev D.B studios)
Games + Smart TV launcher for Windows with Xbox controller support.

Update: copy these files over your existing folder (do not delete node_modules), then `npm start`.
Sign-in: put your Firebase Web API key in firebase-config.json (Firebase console > Authentication > enable Email/Password > Project settings > Web API key). Guest mode needs no key.
Xbox-button / combo listener: see guide-listener.ps1 and install-guide-button.ps1.
